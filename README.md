# 以 LYN 免疫受体激酶为对象的候选分子虚拟发现机器学习方法

> 面向 LYN 在免疫受体信号中的调控作用，建立候选分子虚拟发现流程，助力自身免疫与血液肿瘤靶点探索。

## 一、方法

- **模型**：Chebyshev 谱域图卷积（K 阶多项式逼近）

- **输入**：分子图（原子节点 + 化学键边，RDKit 解析 SMILES 得到）
- **训练规模**：1337 条样本，2 类
- **标签协议**：abs_gap
- **验证**：5 折分层交叉验证 × 3 随机种子 = 15 次独立训练
